```
Formal Targets
  |-- 1. Formal Mathematics
  |   |-- theorem statement formalization
  |   |-- proof generation
  |   `-- proof checking
  |
  `-- 2. Engineered Systems Verification
      |-- 2.1 General Software / Program Verification
      |-- 2.2 Hardware / RTL Verification
      |-- 2.3 Smart Contract / Blockchain Verification
      `-- 2.4 Protocol / Concurrent / Distributed Systems
```

## Benchmark Overview

- **Math** rows verify mathematical statements or proofs. **Software**, **Hardware**, **Contract**, and **Protocol** rows verify engineered artifacts.
- Dates link to the first public paper/resource when available; the second field is included only for an accepted or published venue.
- Method papers with a named, reproducible evaluation set are marked **Eval**. Unverified resources such as Ineq-Comp and proposal-only artifacts such as SWE-Proof are not listed as confirmed benchmarks.
- In the last column, every line follows: **Metric**: `Input -> Output`; **Verify**: evaluation oracle.
